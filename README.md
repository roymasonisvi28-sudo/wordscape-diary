# 《词境恋习日记》

面向男性玩家的中文网页 Galgame 原型：考研英语核心词背诵、校园恋爱剧情、角色养成与章节闯关。

## 快速运行

推荐直接双击 `index.html`。项目不依赖后端，Chrome、Edge、Firefox、Safari 和手机浏览器均可运行。

也可以在安装 Node.js 后运行：

```powershell
npm run dev
```

然后访问 `http://localhost:4173`。

## 首版范围

- 3 位成年女主与完整角色档案，每位包含普通、微笑、害羞、认真、吃醋、失落 6 种上半身表情动作差分。
- 33 章剧情数据：3 章公共序章、每位女主 8 章路线、6 章公共主线。
- 33 章均可挑战、可推进，并配置独立校园事件与连续关系发展。
- 500 个考研英语核心高频词，来自 ECDICT 的 `ky` 标签词条筛选。
- 单一词义互动复习：女主会用符合性格的称呼自然提问，答对答错均进入新的剧情反馈界面并切换表情差分。
- 答对后少量增加心动值，角色头顶会出现跳动小红心。
- 隐藏干扰角色“香蕉君”：随机乱入章节并提出超纲词汇题，答错会触发 5 秒遮屏彩蛋与反向好感。
- 熟练度、错词回廊、好感/信任/共鸣、每日学习、统计、设置、自动与手动存档。
- CC0 校园氛围背景音乐：首次点击后循环播放，可在设置页关闭或调节音量。
- 所有进度保存在浏览器 `localStorage` 中。

## 目录

```text
index.html            网页入口
src/app.js            游戏逻辑
styles/app.css        页面样式与响应式布局
data/*.json           词库、角色、章节、选择与结局数据
data/generated-data.js 双击打开网页时使用的数据包
assets/               原创占位美术说明
docs/                 设计、来源、测试和扩展说明
scripts/generate_data.py 数据生成脚本
tests/basic.test.js    基础数据测试
```

## 扩展词库

首版根据原型目标收敛为 500 个核心高频词。数据结构已保留扩展能力，可调整 `scripts/generate_data.py` 的数量并补充人工校对内容，逐步扩展至约 2000 词。
