# 词库来源与许可证

## 首版来源

- 项目：[ECDICT](https://github.com/skywind3000/ECDICT)
- 数据文件：`ecdict.csv`
- 许可证：MIT License
- 使用方式：筛选同时带有 `ky` 与 `cet4` 标签的基础考研词条，将缺失频次视为未知值，按常用频率排序并去重，抽取 500 个核心高频词。
- 本地许可证副本：`.cache/ECDICT-LICENSE.txt`

ECDICT 为词典基础数据。首版对词条补充了分层、角色绑定、记忆提示、剧情语境和例句字段。少量关键词采用人工编写的自然例句；其余词条使用明确标记为原型内容的通用语境例句，后续发布前应继续人工校对。

## 雪崩竞速储备

- 数据文件：`data/avalanche-words.json` 与浏览器直开版本 `data/avalanche-words.js`
- 规模：2000 个词条
- 使用方式：从 ECDICT 中筛选带有 `ky` 考研标签的英语词条，按常用频率排序并去重，作为张雪崩老师竞速彩蛋的中文选择题储备。
- 说明：该储备用于原型小游戏，并非对任何商业“红宝书”词表的复制或官方复刻。正式发布前建议按目标教材目录人工复核覆盖范围和释义。

## 分层

- 基础核心词：前 220 个
- 中频提升词：中间 180 个
- 高阶抽象词：后 100 个

## 后续扩展

正式扩展到约 2000 词时，建议保留 ECDICT 作为字段基础，增加人工复核表，重点复核词性、常见义项、自然例句、易混词组和章节绑定。
